# effi-factory

Маленький список справ для прогону [Effi factory](https://github.com/kirichok/effi-factory). Застосунок тримає завдання в пам’яті: додати, позначити виконаним, видалити.

```bash
yarn test
```

Потрібен Node 22. Каталог `docs/project/` — шлях знань фабрики: після прийняття pull request туди потрапляє запис про завдання.
